# Student Grade & GPA Calculator (Java)

A Java-based application designed to process numerical scores, determine letter grades based on predefined grading scales, and compute overall class or student grade point averages (GPA).

## Features
- **Grade Calculation:** Automatically converts raw numerical marks into standard letter grades (A, B, C, etc.).
- **Average & GPA Processing:** Computes cumulative averages and weighted scores across multiple course inputs.
- **Input Validation:** Handles data entry logic to ensure scores fall within valid academic bounds.

## Tech Stack
- **Language:** Java (JDK 8+)
- **Core Concepts:** Object-Oriented Programming (OOP), Control Flow, Input Parsing
